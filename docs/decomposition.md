# Декомпозиция проекта Брифер

## Принципы разработки

- **SDD** (Specification Driven Development) — все задачи и задания агентам формулируются через спецификации: чёткий ввод, ожидаемый вывод, критерии приёмки
- **TDD** (Test Driven Development) — тесты пишутся до реализации. Red → Green → Refactor
- **SOLID** — единая ответственность, открытость/закрытость, подстановка Лисков, разделение интерфейсов, инверсия зависимостей
- **DRY** — нет дублирования логики. Выносим повторяющееся в функции/классы
- **ООП** — моделируем домен сущностями (AudioFile, Transcript, Summary, Task, Result), а не размазываем по функциям
- **Без оверинжиниринга** — минимум абстракций, необходимых для текущей задачи. Не создаём интерфейсы «на будущее»
