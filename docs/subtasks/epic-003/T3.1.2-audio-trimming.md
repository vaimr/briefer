# T3.1.2 — Add Audio Trimming for Whisper

## Цель
Реализовать обрезку аудиофайлов для Whisper (макс. 25MB).

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| input_path | Check size → trim if needed | output_path |
| input_path, max_size_mb | Check custom size | output_path |

## Пошаговый план

1. Создать `worker/audio_trim.py`:

```python
"""Audio file trimming for Whisper compatibility."""

import logging
import os
import shutil
import subprocess
from pathlib import Path
from typing import Optional

logger = logging.getLogger(__name__)


class AudioTrimError(Exception):
    """Audio trimming failed."""


class AudioTrimmer:
    """Trim audio files for Whisper compatibility."""

    MAX_FILE_SIZE = 25 * 1024 * 1024  # 25 MB
    MAX_DURATION_SECONDS = 300  # 5 minutes (Whisper limit)

    def __init__(
        self,
        ffmpeg_path: Optional[str] = None,
        max_file_size: int = MAX_FILE_SIZE,
        max_duration: float = MAX_DURATION_SECONDS,
    ):
        """Initialize audio trimmer.

        Args:
            ffmpeg_path: Path to ffmpeg binary.
            max_file_size: Maximum file size in bytes.
            max_duration: Maximum duration in seconds.
        """
        self.ffmpeg_path = ffmpeg_path or shutil.which("ffmpeg")
        self.max_file_size = max_file_size
        self.max_duration = max_duration

        if not self.ffmpeg_path:
            raise AudioTrimError("ffmpeg not found in PATH")

    def trim(self, input_path: str, output_path: Optional[str] = None) -> str:
        """Trim audio file if needed.

        Args:
            input_path: Path to input audio file.
            output_path: Path to output file. If None, appends _trimmed to input.

        Returns:
            Path to output file (original if no trim needed).

        Raises:
            AudioTrimError: On trimming failure.
        """
        input_path = str(input_path)

        if not os.path.exists(input_path):
            raise AudioTrimError(f"File not found: {input_path}")

        file_size = os.path.getsize(input_path)

        # Check if trimming is needed
        if file_size <= self.max_file_size:
            logger.info(f"File {input_path} ({file_size} bytes) is within limits")
            return input_path

        # File needs trimming
        if output_path is None:
            output_path = str(Path(input_path).with_suffix(
                Path(input_path).suffix + "_trimmed.wav"
            ))

        logger.info(f"Trimming {input_path} ({file_size} bytes) -> {output_path}")

        # Trim to max duration
        cmd = [
            self.ffmpeg_path,
            "-i", input_path,
            "-t", str(self.max_duration),
            "-ar", "16000",
            "-ac", "1",
            "-f", "wav",
            "-y",
            output_path,
        ]

        try:
            result = subprocess.run(
                cmd,
                capture_output=True,
                timeout=300,
                check=True,
            )
            logger.info(f"Trimming successful: {output_path}")
            return output_path

        except subprocess.CalledProcessError as e:
            stderr = e.stderr.decode("utf-8", errors="replace") if e.stderr else ""
            raise AudioTrimError(f"ffmpeg failed: {stderr}") from e
        except subprocess.TimeoutExpired:
            raise AudioTrimError("Trimming timed out") from None

    def needs_trimming(self, input_path: str) -> bool:
        """Check if file needs trimming.

        Args:
            input_path: Path to file.

        Returns:
            True if file needs trimming.
        """
        if not os.path.exists(input_path):
            return False

        file_size = os.path.getsize(input_path)
        return file_size > self.max_file_size
```

## Граничные случаи

- Файл не существует — AudioTrimError("not found")
- Файл 25MB - 1 байт — не обрезается
- Файл 25MB — не обрезается (<=)
- Файл 25MB + 1 байт — обрезается
- Файл 100MB — обрезается
- output_path не указан — appends _trimmed.wav
- output_path указан — используется
- ffmpeg не установлен — AudioTrimError("not found")
- ffmpeg exit code != 0 — AudioTrimError
- ffmpeg timeout > 300s — AudioTrimError("timed out")
- needs_trimming: файл < 25MB → False
- needs_trimming: файл > 25MB → True
- needs_trimming: файл не существует → False
