# T1.1.3 — Create .gitignore

## Цель
Создать полный `.gitignore` с учётом всех артефактов проекта.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| — | Генерация `.gitignore` файла | Файл с правилами игнорирования |

## Пошаговый план

1. Создать `.gitignore` с секциями:

   ```gitignore
   # Python
   __pycache__/
   *.py[cod]
   *.so
   .Python
   build/
   develop-eggs/
   dist/
   downloads/
   eggs/
   .eggs/
   lib/
   lib64/
   parts/
   sdist/
   var/
   wheels/
   *.egg-info/
   .installed.cfg
   *.egg

   # Virtual Environment
   .venv/
   venv/
   ENV/

   # Environment Variables
   .env
   .env.local
   .env.production

   # IDE
   .idea/
   .vscode/
   *.swp
   *.swo
   *~

   # OS
   .DS_Store
   Thumbs.db

   # Test Coverage
   .coverage
   .coverage.*
   htmlcov/
   .pytest_cache/

   # Mypy
   .mypy_cache/

   # Documentation
   docs/_build/

   # Docker
   Docker/
   *.whl
   .tox/

   # Logs
   *.log
   *.tmp
   *.bak

   # DO NOT IGNORE
   .env.example
   ```

2. Убедиться, что `.env.example` НЕ игнорируется.
3. Проверить валидность через `git check-ignore`.

## Граничные случаи

- `.env` игнорируется, но `.env.example` — нет
- `__pycache__/` — каталог, нужен слэш
- Пустой `.gitignore` — все файлы отслеживаются
- Пустой проект — `.gitignore` должен работать до появления файлов

## Тесты (TDD)

- `tests/unit/test_gitignore.py`:
  - `test_gitignore_file_exists()` — `.gitignore` существует
  - `test_gitignore_contains_python_rules()` — содержит `__pycache__/`, `*.pyc`
  - `test_gitignore_contains_env_rules()` — содержит `.env`, но не `.env.example`
  - `test_gitignore_contains_ide_rules()` — содержит `.idea/`, `.vscode/`
  - `test_gitignore_contains_test_cache_rules()` — содержит `.pytest_cache/`, `.coverage`
  - `test_gitignore_contains_docker_rules()` — содержит `Docker/`, `*.whl`
  - `test_gitignore_does_not_ignore_env_example()` — `.env.example` НЕ в правилах
  - `test_gitignore_contains_log_rules()` — содержит `*.log`, `*.tmp`
  - `test_gitignore_is_valid()` — `git check-ignore .env` возвращает 0
  - `test_gitignore_is_valid_env_example()` — `git check-ignore .env.example` возвращает 1
