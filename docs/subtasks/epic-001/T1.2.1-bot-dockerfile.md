# T1.2.1 — Create Bot Dockerfile

## Цель
Создать оптимизированный Dockerfile для bot сервиса.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| Dockerfile + bot/ код | `docker build` | Образ `bot:latest` (~200MB) |

## Пошаговый план

1. Создать `bot/Dockerfile`:

   ```dockerfile
   FROM python:3.11-slim

   WORKDIR /app

   # Install system dependencies
   RUN apt-get update && apt-get install -y --no-install-recommends \
       gcc \
       && rm -rf /var/lib/apt/lists/*

   # Copy requirements first for layer caching
   COPY requirements.txt .
   RUN pip install --no-cache-dir -r requirements.txt

   # Copy application code
   COPY . .

   # Health check
   HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
       CMD python -c "import bot; print('Bot OK')" || exit 1

   # Entry point
   ENTRYPOINT ["python", "-m", "bot.main"]
   ```

2. Создать `bot/requirements.txt`:
   ```
   matrix-nio>=1.6.0
   aiomysql>=0.2.0
   redis>=5.0.0
   pydantic-settings>=2.0.0
   python-dotenv>=1.0.0
   structlog>=23.0.0
   prometheus-client>=0.19.0
   ```

3. Проверить валидность: `docker build -t bot-test -f bot/Dockerfile bot/`

## Граничные случаи

- Ошибка установки зависимостей — `pip install` должен завершиться с ошибкой
- Отсутствие `requirements.txt` — `COPY` вернёт ошибку
- Образ слишком большой — использовать `slim` базовый образ
- Healthcheck не отвечает — контейнер помечается как unhealthy
