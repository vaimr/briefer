# T1.2.3 — Validate docker-compose.yml

## Цель
Создать и валидировать `docker-compose.yml` с тремя сервисами.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| docker-compose.yml | `docker compose config` | Валидная конфигурация |

## Пошаговый план

1. Создать `docker-compose.yml`:

   ```yaml
   version: "3.8"

   services:
     redis:
       image: redis:7-alpine
       ports:
         - "6379:6379"
       volumes:
         - redis_data:/data
       restart: always
       healthcheck:
         test: ["CMD", "redis-cli", "ping"]
         interval: 10s
         timeout: 5s
         retries: 5

     bot:
       build:
         context: .
         dockerfile: bot/Dockerfile
       depends_on:
         redis:
           condition: service_healthy
       environment:
         - MATRIX_USER=${MATRIX_USER}
         - MATRIX_PASSWORD=${MATRIX_PASSWORD}
         - MATRIX_HOMESERVER=${MATRIX_HOMESERVER}
       volumes:
         - bot_logs:/app/logs
       restart: always
       healthcheck:
         test: ["CMD", "python", "-c", "import bot; print('OK')"]
         interval: 30s
         timeout: 10s
         start_period: 30s
         retries: 3

     worker:
       build:
         context: .
         dockerfile: worker/Dockerfile
       depends_on:
         redis:
           condition: service_healthy
       environment:
         - REDIS_URL=redis://redis:6379
         - WHISPER_MODEL=large-v3
         - WHISPER_DEVICE=cpu
         - LLM_API_URL=${LLM_API_URL}
         - LLM_API_KEY=${LLM_API_KEY}
         - LLM_MODEL=${LLM_MODEL}
       volumes:
         - worker_logs:/app/logs
       restart: always
       healthcheck:
         test: ["CMD", "python", "-c", "import worker; print('OK')"]
         interval: 30s
         timeout: 10s
         start_period: 60s
         retries: 3

   volumes:
     redis_data:
     bot_logs:
     worker_logs:
   ```

2. Выполнить `docker compose config` для валидации.
3. Выполнить `docker compose up -d` для проверки запуска.

## Граничные случаи

- redis не healthcheck'd — bot и worker не запустятся
- `condition: service_healthy` — зависит от healthcheck redis
- Переменные окружения не заданы — подставятся пустые значения
- Volumes не существуют — docker создаст автоматически
- `restart: always` — сервис перезапускается при краше
