# T1.3.3 — Create Matrix Mock Fixture

## Цель
Создать fixture для mock-матрицы в тестах, имитирующего matrix-nio Client.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| Вызов mock-Matrix методов | Возврат предопределённых значений | Результаты Matrix-операций |

## Пошаговый план

1. Создать `tests/fixtures/matrix_mock.py`:

   ```python
   """Mock Matrix fixtures for testing without real Matrix server."""

   from unittest.mock import MagicMock
   import pytest


   @pytest.fixture
   def mock_matrix_event():
       """Mock MatrixEvent object."""
       event = MagicMock()
       event.event_id = "$event_001"
       event.room_id = "!room:example.com"
       event.type = "m.room.message"
       event.sender = "@user:example.com"
       event.content = {
           "msgtype": "m.text",
           "body": "Hello, world!",
       }
       event.is_state = False
       event.origin_server_ts = 1700000000000
       return event


   @pytest.fixture
   def mock_matrix_room():
       """Mock Matrix Room object."""
       room = MagicMock()
       room.room_id = "!room:example.com"
       room.name = "Test Room"
       room.send.return_value = "$sent_event_001"
       room.sync.return_value = True
       room.get_event_history.return_value = []
       return room


   @pytest.fixture
   def mock_matrix_client():
       """Mock matrix-nio Client object."""
       client = MagicMock()
       client.user_id = "@bot:example.com"
       client.room_id = "!room:example.com"

       # Authentication
       client.login.return_value = True
       client.sync.return_value = True
       client.sync_loop.return_value = None

       # Messaging
       client.send_text_message.return_value = "$msg_001"
       client.send.return_value = "$msg_002"

       # Room operations
       client.join_room.return_value = MagicMock(room_id="!joined:example.com")
       client.get_room_id.return_value = "!room:example.com"
       client.rooms.return_value = {"!room:example.com": MagicMock(room_id="!room:example.com")}

       # Event handling
       client.listeners = []
       client.add_listener.return_value = 0

       # Presence
       client.set_presence.return_value = True

       return client
   ```

2. Создать `tests/unit/test_matrix_mock.py` для проверки fixtures.

## Граничные случаи

- `send()` возвращает `None` если комната не найдена
- `login()` вызывает ошибку при неверных credentials
- `sync_loop()` — бесконечный цикл, нужно mock-ить return_value
- `get_room_id()` возвращает `None` для несуществующей комнаты
- `add_listener()` возвращает ID listener'а
