# T1.4.1 — Create Base Configuration Module

## Цель
Создать базовый модуль конфигурации с Pydantic Settings.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| Environment variables | Pydantic Settings parsing | Typed configuration objects |

## Пошаговый план

1. Создать `bot/config.py`:

   ```python
   """Bot configuration using Pydantic Settings."""

   from pydantic import Field
   from pydantic_settings import BaseSettings, SettingsConfigDict


   class SharedConfig(BaseSettings):
       """Shared configuration between bot and worker."""

       model_config = SettingsConfigDict(
           env_file=".env",
           env_file_encoding="utf-8",
           case_sensitive=False,
       )

       log_level: str = "INFO"
       log_format: str = "json"
       redis_url: str = "redis://localhost:6379/0"
       metrics_enabled: bool = True


   class WorkerConfig(SharedConfig):
       """Worker-specific configuration."""

       whisper_model: str = "large-v3"
       whisper_device: str = "cpu"
       whisper_compute_type: str = "int8"
       llm_api_url: str = "http://localhost:8000/v1"
       llm_api_key: str = ""
       llm_model: str = "gpt-4"
       pdf_output_dir: str = "/app/output"


   class BotConfig(SharedConfig):
       """Bot-specific configuration."""

       matrix_user: str = ""
       matrix_password: str = ""
       matrix_homeserver: str = "https://matrix.org"
       matrix_device_name: str = "briefer-bot"
       matrix_autojoin_rooms: list[str] = Field(default_factory=list)
       matrix_bot_display_name: str = "Briefer Bot"
   ```

2. Создать `tests/unit/test_config.py` для проверки конфигурации.

## Граничные случаи

- Отсутствующее env-переменная — используется default value
- Пустая строка в env — используется пустая строка (не default)
- Невалидный URL в `redis_url` — Pydantic валидация
- Невалидный log_level — должно быть INFO/DEBUG/WARNING/ERROR
- `autojoin_rooms` — пустой список по умолчанию
- `llm_api_key` — пустая строка до установки
