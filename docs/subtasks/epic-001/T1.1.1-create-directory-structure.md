# T1.1.1 — Create Directory Structure

## Цель
Создать полную структуру каталогов проекта согласно архитектуре.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| — | Создание 12+ каталогов | Файловая структура проекта |

## Пошаговый план

1. Создать каталоги верхнего уровня:
   ```
   bot/
   worker/
   tests/
   docs/
   ```

2. Создать подкаталоги `bot/`:
   ```
   bot/
   ├── __init__.py
   ├── config.py
   ├── main.py
   └── handlers/
       ├── __init__.py
       └── matrix_handler.py
   ```

3. Создать подкаталоги `worker/`:
   ```
   worker/
   ├── __init__.py
   ├── chunking.py
   ├── llm_client.py
   ├── whisper_wrapper.py
   └── pdf_generator.py
   ```

4. Создать подкаталоги `tests/`:
   ```
   tests/
   ├── __init__.py
   ├── conftest.py
   ├── unit/
   │   ├── __init__.py
   │   └── test_*.py
   └── integration/
       ├── __init__.py
       └── test_*.py
   ```

5. Создать подкаталоги `docs/`:
   ```
   docs/
   ├── epics/
   ├── tasks/
   └── subtasks/
   ```

6. Создать пустые `__init__.py` во всех пакетах.

7. Создать `.gitkeep` в `docs/epics/`, `docs/tasks/`, `docs/subtasks/`.

## Граничные случаи

- Путь к каталогу уже существует — `mkdir -p` не должен вызывать ошибку
- Права доступа на запись — проверка при создании
- Специальные символы в путях — не используются
- Вложенность каталогов — создание через `os.makedirs(exist_ok=True)`

## Тесты (TDD)

- `tests/unit/test_directory_structure.py`:
  - `test_bot_directory_exists()` — проверяет существование `bot/`
  - `test_worker_directory_exists()` — проверяет существование `worker/`
  - `test_tests_directory_exists()` — проверяет существование `tests/`
  - `test_docs_directory_exists()` — проверяет существование `docs/`
  - `test_bot_handlers_subdirectory_exists()` — проверяет `bot/handlers/`
  - `test_tests_unit_subdirectory_exists()` — проверяет `tests/unit/`
  - `test_tests_integration_subdirectory_exists()` — проверяет `tests/integration/`
  - `test_init_files_exist()` — проверяет все `__init__.py`
  - `test_gitkeep_files_exist()` — проверяет `.gitkeep` в docs/
