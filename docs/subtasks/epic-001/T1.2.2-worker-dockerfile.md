# T1.2.2 — Create Worker Dockerfile

## Цель
Создать оптимизированный Dockerfile для worker сервиса с предзагрузкой Whisper.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| Dockerfile + worker/ код | `docker build` | Образ `worker:latest` (~2-3GB) |

## Пошаговый план

1. Создать `worker/Dockerfile`:

   ```dockerfile
   FROM python:3.11-slim

   WORKDIR /app

   # Install system dependencies
   RUN apt-get update && apt-get install -y --no-install-recommends \
       build-essential \
       ffmpeg \
       pandoc \
       git \
       && rm -rf /var/lib/apt/lists/*

   # Copy requirements first for layer caching
   COPY requirements.txt .
   RUN pip install --no-cache-dir -r requirements.txt

   # Preload Whisper model (int8, CPU)
   RUN python -c "from faster_whisper import WhisperModel; WhisperModel('large-v3', device='cpu', compute_type='int8')"

   # Copy application code
   COPY . .

   # Health check
   HEALTHCHECK --interval=30s --timeout=10s --start-period=60s --retries=3 \
       CMD python -c "import worker; print('Worker OK')" || exit 1

   # Entry point
   ENTRYPOINT ["python", "-m", "worker.main"]
   ```

2. Создать `worker/requirements.txt`:
   ```
   faster-whisper>=1.0.0
   openai>=1.0.0
   requests>=2.31.0
   redis>=5.0.0
   pydantic-settings>=2.0.0
   python-dotenv>=1.0.0
   reportlab>=4.0.0
   structlog>=23.0.0
   prometheus-client>=0.19.0
   ```

3. Проверить валидность: `docker build -t worker-test -f worker/Dockerfile worker/`

## Граничные случаи

- Предзагрузка модели занимает ~5 минут — healthcheck `--start-period=60s`
- Модель large-v3 int8 занимает ~1GB — образ будет большим
- ffmpeg нужен для аудио — без него transcribe упадёт
- pandoc нужен для PDF — без него PDF generation упадёт
- `--no-install-recommends` уменьшает образ
