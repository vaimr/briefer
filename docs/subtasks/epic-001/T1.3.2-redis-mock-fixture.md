2. Создать `tests/unit/test_redis_mock.py` для проверки fixtures.

## Граничные случаи

- `get()` возвращает `None` для отсутствующего ключа
- `delete()` возвращает 0 для несуществующего ключа
- `lpop()`/`rpop()` возвращают `None` для пустого списка
- `expire()` возвращает `False` для несуществующего ключа
- `hget()` возвращает `None` для несуществующего поля
- `get_message()` возвращает `None` когда нет сообщений
