# T1.5.1 — Create GitHub Actions CI Pipeline

## Цель
Создать CI pipeline для линтинга, тестирования и сборки Docker.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| Push/Pull Request | lint + test + build | Status check: pass/fail |

## Пошаговый план

1. Создать `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

env:
  PYTHON_VERSION: "3.11"

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install ruff mypy

      - name: Run ruff check
        run: ruff check .

      - name: Run ruff format
        run: ruff format --check .

      - name: Run mypy
        run: mypy bot/ worker/ --ignore-missing-imports

  test:
    name: Test
    runs-on: ubuntu-latest
    needs: [lint]
    services:
      redis:
        image: redis:7-alpine
        ports:
          - 6379:6379
        options: >-
          --health-cmd "redis-cli ping"
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r bot/requirements.txt
          pip install -r worker/requirements.txt
          pip install pytest pytest-cov

      - name: Run tests
        env:
          REDIS_URL: redis://localhost:6379/0
        run: |
          pytest -v --cov=bot --cov=worker \
            --cov-report=xml --cov-report=term-missing \
            --cov-fail-under=80

      - name: Upload coverage
        uses: codecov/codecov-action@v4
        with:
          files: ./coverage.xml
          fail_ci_if_error: false

  build:
    name: Build Docker
    runs-on: ubuntu-latest
    needs: [test]
    steps:
      - uses: actions/checkout@v4

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3

      - name: Build bot image
        run: docker compose build bot

      - name: Build worker image
        run: docker compose build worker
```

2. Создать `.github/workflows/docker-publish.yml` (опционально, для push в main).

3. Проверить валидность: `actionlint .github/workflows/ci.yml`.

## Граничные случаи

- Push не на main/develop — CI не запускается
- PR из fork — secrets не доступны
- Redis service не healthcheck'd — test job падает
- Coverage < 80% — CI падает (`--cov-fail-under=80`)
- Lint fails — test job не запускается (`needs: [lint]`)
- Docker build fails — build job падает, но test уже прошёл

- [ ] Три jobs: `lint`, `test`, `build`
- [ ] Job `lint`: `ruff check`, `ruff format --check`, `mypy`

- [ ] Coverage threshold: `--cov-fail-under=80`
- [ ] Job dependencies: `test` зависит от `lint`, `build` зависит от `test`
