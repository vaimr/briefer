# T1.3.1 — Create pytest.ini and conftest.py

## Цель
Создать конфигурацию pytest и базовый `conftest.py` с fixtures.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| pytest config | Настройка markers, options | Конфигурация тестового фреймворка |

## Пошаговый план

1. Создать `pyproject.toml` с секцией pytest:

   ```toml
   [tool.pytest.ini_options]
   testpaths = ["tests"]
   python_files = ["test_*.py"]
   python_classes = ["Test*"]
   python_functions = ["test_*"]
   markers = [
       "unit: Unit tests",
       "integration: Integration tests",
       "slow: Slow tests",
       "redis: Tests requiring Redis",
       "matrix: Tests requiring Matrix",
       "whisper: Tests requiring Whisper",
   ]
   addopts = "-v --tb=short --strict-markers --cov=bot --cov=worker --cov-report=term-missing"
   filterwarnings = [
       "ignore::DeprecationWarning",
       "ignore::PendingDeprecationWarning",
   ]

   [tool.coverage.run]
   source = ["bot", "worker"]
   omit = [
       "*/tests/*",
       "*/__init__.py",
       "*/migrations/*",
   ]

   [tool.coverage.report]
   exclude_lines = [
       "pragma: no cover",
       "def __repr__",
       "if __name__ == .__main__.",
       "raise NotImplementedError",
   ]
   ```

2. Создать `tests/conftest.py`:

   ```python
   """Shared pytest fixtures for all tests."""

   import pytest
   from pathlib import Path


   @pytest.fixture
   def project_root() -> Path:
       """Root of the project."""
       return Path(__file__).parent.parent


   @pytest.fixture
   def tmp_project_dir(tmp_path: Path) -> Path:
       """Temporary directory for project-level tests."""
       return tmp_path


   @pytest.fixture
   def sample_transcription() -> str:
       """Sample transcription text for testing."""
       return (
           "This is a sample transcription text. "
           "It contains multiple sentences. "
           "Each sentence ends with a period. "
           "This helps test the chunking logic properly."
       )


   @pytest.fixture
   def sample_audio_path(tmp_path: Path) -> Path:
       """Sample audio file path for testing."""
       audio_file = tmp_path / "sample.wav"
       audio_file.write_bytes(b"fake audio data")
       return audio_file
   ```

3. Проверить: `pytest --collect-only` не генерирует ошибок.
4. Проверить: `pytest --markers` показывает все markers.

## Граничные случаи

- Пустой `pyproject.toml` — pytest использует defaults
- Невалидные markers — `--strict-markers` вызовет ошибку
- Дубликаты fixtures — pytest выберет ближайший к тесту
- `filterwarnings` — пустой список = все warnings как ошибки
