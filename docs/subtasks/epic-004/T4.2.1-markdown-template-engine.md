# T4.2.1 — Create Markdown Template Engine

## Цель
Создать систему шаблонов для формирования markdown сводки.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| Транскрипция + саммари | Рендер шаблонов | Markdown текст |
| Транскрипция | Рендер транскрипции | Markdown транскрипции |

## Пошаговый план

1. Создать `worker/templates.py`:

```python
"""Markdown template engine for summaries and transcriptions."""

from datetime import datetime
from typing import Dict, List, Optional


class SummaryTemplate:
    """Template engine for generating markdown summaries."""

    SUMMARY_TEMPLATE = """# Сводка транскрипции

**Дата:** {date}
**Длительность:** {duration}

## Краткое содержание

{summary}

## Ключевые моменты

{key_points}

---
*Сгенерировано автоматически*
"""

    TRANSCRIPTION_TEMPLATE = """# Транскрипция

**Дата:** {date}
**Длительность:** {duration}

{transcription}

---
*Сгенерировано автоматически*
"""

    @staticmethod
    def render_summary(
        summary: str,
        date: Optional[str] = None,
        duration: str = "N/A",
        key_points: Optional[List[str]] = None,
    ) -> str:
        """Render summary template.

        Args:
            summary: Summary text.
            date: Date string. Defaults to current date.
            duration: Duration string.
            key_points: List of key points.

        Returns:
            Rendered markdown string.
        """
        if date is None:
            date = datetime.now().strftime("%Y-%m-%d %H:%M")

        if key_points:
            key_points_text = "\n".join(f"- {point}" for point in key_points)
        else:
            key_points_text = "*Нет ключевых моментов*"

        return SummaryTemplate.SUMMARY_TEMPLATE.format(
            date=date,
            duration=duration,
            summary=summary,
            key_points=key_points_text,
        )

    @staticmethod
    def render_transcription(
        transcription: str,
        date: Optional[str] = None,
        duration: str = "N/A",
    ) -> str:
        """Render transcription template.

        Args:
            transcription: Transcription text.
            date: Date string. Defaults to current date.
            duration: Duration string.

        Returns:
            Rendered markdown string.
        """
        if date is None:
            date = datetime.now().strftime("%Y-%m-%d %H:%M")

        return SummaryTemplate.TRANSCRIPTION_TEMPLATE.format(
            date=date,
            duration=duration,
            transcription=transcription,
        )

    @staticmethod
    def render_with_context(
        context: Dict[str, str],
        template: str,
    ) -> str:
        """Render arbitrary template with context.

        Args:
            context: Dict of template variables.
            template: Template string with {variable} placeholders.

        Returns:
            Rendered string.
        """
        return template.format(**context)
```

2. Создать `tests/unit/test_templates.py` для проверки.

## Граничные случаи

- Пустая транскрипция — шаблон рендерится с пустым текстом
- Пустое саммари — шаблон рендерится с пустым текстом
- `date = None` — используется current datetime
- `key_points = []` — пустой список → "*Нет ключевых моментов*"
- `key_points = None` — тот же результат
- Специальные символы в тексте — markdown экранирование
- Очень длинное саммари — шаблон рендерится без обрезки
- Пустой контекст для `render_with_context` — KeyError если переменная отсутствует
