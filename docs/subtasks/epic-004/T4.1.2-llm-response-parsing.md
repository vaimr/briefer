# T4.1.2 — Add LLM Response Parsing

## Цель
Реализовать парсинг ответов LLM API и обработку ошибок.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| JSON response | Парсинг → LLMResponse | LLMResponse с полями |
| HTTP error | Классификация → Exception | Специфичная ошибка |

## Пошаговый план

1. Создать `worker/llm_response.py`:

```python
"""LLM response parsing and error handling."""

from dataclasses import dataclass
from typing import Optional


@dataclass
class LLMResponse:
    """Parsed response from LLM API."""
    text: str = ""
    tokens_used: int = 0
    finish_reason: str = ""
    model: str = ""


class LLMResponseParseError(Exception):
    """Failed to parse LLM response."""


class LLMResponseValidationError(Exception):
    """Response validation failed."""


def parse_llm_response(data: dict) -> LLMResponse:
    """Parse LLM API JSON response into LLMResponse.

    Args:
        data: JSON response from LLM API.

    Returns:
        Parsed LLMResponse.

    Raises:
        LLMResponseParseError: If response structure is invalid.
    """
    if "choices" not in data:
        raise LLMResponseParseError("Response missing 'choices' field")

    choices = data["choices"]
    if not choices:
        raise LLMResponseParseError("Response has empty 'choices'")

    choice = choices[0]
    if "message" not in choice:
        raise LLMResponseParseError("Choice missing 'message' field")

    message = choice["message"]
    if "content" not in message:
        raise LLMResponseParseError("Message missing 'content' field")

    response = LLMResponse(
        text=message["content"],
        finish_reason=choice.get("finish_reason", ""),
        model=data.get("model", ""),
    )

    # Parse token usage
    usage = data.get("usage", {})
    if usage:
        response.tokens_used = usage.get("total_tokens", 0)

    # Validate
    if not response.text:
        raise LLMResponseValidationError("Response text is empty")

    return response


def validate_llm_response(response: LLMResponse) -> bool:
    """Validate LLMResponse fields.

    Args:
        response: LLMResponse to validate.

    Returns:
        True if valid.

    Raises:
        LLMResponseValidationError: If validation fails.
    """
    if not response.text:
        raise LLMResponseValidationError("Text is empty")

    if response.tokens_used < 0:
        raise LLMResponseValidationError(f"Negative token count: {response.tokens_used}")

    if response.finish_reason not in ("stop", "length", "content_filter", ""):
        raise LLMResponseValidationError(f"Unknown finish_reason: {response.finish_reason}")

    return True
```

2. Создать `tests/unit/test_llm_response.py` для проверки.

## Граничные случаи

- `choices` пустой список — LLMResponseParseError
- `choices[0].message` отсутствует — LLMResponseParseError
- `choices[0].message.content` пустая строка — LLMResponseValidationError
- `usage` отсутствует — tokens_used = 0
- `usage.total_tokens` отрицательный — LLMResponseValidationError
- `finish_reason` невалидный — LLMResponseValidationError
- `data` — None — KeyError при доступе к полям
