# T2.5.2 — Add Bot Graceful Shutdown

## Цель
Реализовать graceful shutdown бота с корректным освобождением ресурсов.

## Spec

| Input | Processing | Output |
|-------|-----------|--------|
| SIGINT/SIGTERM | async shutdown → cleanup | Clean exit |
| stop() | async stop → cleanup | Clean exit |

## Пошаговый план

1. Создать `bot/shutdown.py`:

```python
"""Graceful shutdown handling for the bot."""

import asyncio
import logging
import signal
from typing import Callable, Dict, Optional

logger = logging.getLogger(__name__)


class ShutdownHandler:
    """Handle graceful bot shutdown."""

    def __init__(
        self,
        cleanup_callbacks: Optional[Dict[str, Callable]] = None,
    ):
        """Initialize shutdown handler.

        Args:
            cleanup_callbacks: Dict of callback name → async callable.
        """
        self.cleanup_callbacks = cleanup_callbacks or {}
        self._running = True
        self._shutdown_event = asyncio.Event()
        self._cleanup_done = False

    def register_cleanup(self, name: str, callback: Callable) -> None:
        """Register a cleanup callback.

        Args:
            name: Callback name.
            callback: Async callable to run on shutdown.
        """
        self.cleanup_callbacks[name] = callback
        logger.info(f"Registered cleanup callback: {name}")

    async def start(self) -> None:
        """Start shutdown handler with signal handlers."""
        loop = asyncio.get_running_loop()
        for sig in (signal.SIGINT, signal.SIGTERM):
            loop.add_signal_handler(sig, self._on_signal)

        logger.info("Shutdown handler started")

    def _on_signal(self) -> None:
        """Handle signal."""
        logger.info("Shutdown signal received")
        self._running = False
        self._shutdown_event.set()

    async def run_until_shutdown(self, coro: asyncio.coroutine) -> None:
        """Run a coroutine until shutdown signal.

        Args:
            coro: Coroutine to run.
        """
        await self.start()
        try:
            await coro
        except asyncio.CancelledError:
            logger.info("Coroutine cancelled")
        finally:
            await self.cleanup()

    async def cleanup(self) -> None:
        """Run all cleanup callbacks."""
        if self._cleanup_done:
            return

        self._cleanup_done = True
        logger.info("Running cleanup...")

        # Run all cleanup callbacks in order
        for name, callback in self.cleanup_callbacks.items():
            try:
                if asyncio.iscoroutinefunction(callback):
                    await callback()
                else:
                    callback()
                logger.info(f"Cleanup callback '{name}' completed")
            except Exception as e:
                logger.error(f"Cleanup callback '{name}' failed: {e}")

        logger.info("Cleanup completed")

    @property
    def is_running(self) -> bool:
        """Check if bot is running."""
        return self._running

    @property
    def is_shutdown(self) -> bool:
        """Check if shutdown was requested."""
        return self._shutdown_event.is_set()

    @property
    def cleanup_completed(self) -> bool:
        """Check if cleanup was completed."""
        return self._cleanup_done
```

2. Интегрировать в `bot/bot.py` (добавить shutdown_handler в Bot.start/stop).

3. Создать `tests/unit/test_shutdown.py` для проверки.

## Граничные случаи

- cleanup_callbacks пустой — ничего не происходит
- cleanup_callbacks с 1 callback — вызывается
- cleanup_callbacks с 5 callbacks — все вызываются
- Callback raises — error logged, следующие продолжаются
- Callback async — await'ится
- Callback sync — вызывается напрямую
- cleanup() вызван дважды — второй раз ничего не делает
- start() без register_cleanup — signal handlers работают
- SIGINT во время cleanup — ignore (already cleaning up)
- SIGTERM во время cleanup — ignore
- is_running при shutdown — False
- is_shutdown при run — False
- cleanup_completed до cleanup — False
- cleanup_completed после cleanup — True
