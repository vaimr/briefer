# T5.2.2 — Add Media Upload to Bot

## Цель
Реализовать загрузку медиафайлов (PDF, аудио) в Matrix через Matrix client API.

## Spec

| Поле | Описание |
|------|----------|
| **Вход** | `file_path: str` — путь к файлу; `room_id: str` — Matrix room ID; `message: str` — caption/описание файла; `msgtype: Optional[str]` — MIME-тип (опционально) |
| **Обработка** | 1. Проверка существования файла. 2. Определение MIME-типа по расширению. 3. Загрузка через Matrix upload API. 4. Отправка с caption. |
| **Выход** | `str` — Matrix event ID загруженного сообщения |

## Пошаговый план

1. **Создать `bot/media_uploader.py`**:
```python
import os
import logging
from typing import Optional

logger = logging.getLogger(__name__)

class MediaUploader:
    """Upload media files to Matrix rooms."""

    MIME_TYPES = {
        ".pdf": "application/pdf",
        ".wav": "audio/wav",
        ".mp3": "audio/mpeg",
        ".ogg": "audio/ogg",
        ".jpg": "image/jpeg",
        ".jpeg": "image/jpeg",
        ".png": "image/png",
        ".webm": "video/webm",
    }

    def __init__(self, matrix_client):
        self.matrix_client = matrix_client

    def upload_media(
        self,
        file_path: str,
        room_id: str,
        message: str = "",
        msgtype: Optional[str] = None,
    ) -> str:
        """Upload a media file to a Matrix room.

        Args:
            file_path: Path to the file to upload.
            room_id: Matrix room ID.
            message: Caption/description for the file.
            msgtype: Override MIME type. If None, inferred from extension.

        Returns:
            Matrix event ID of the sent message.
        """
        if not os.path.isfile(file_path):
            raise FileNotFoundError(f"File not found: {file_path}")

        if msgtype is None:
            _, ext = os.path.splitext(file_path)
            msgtype = self.MIME_TYPES.get(ext.lower(), "application/octet-stream")

        with open(file_path, "rb") as f:
            content = f.read()

        upload_result = self.matrix_client.upload(
            content,
            content_type=msgtype,
            filename=os.path.basename(file_path),
        )

        event_id = self.matrix_client.send_event(
            room_id,
            {
                "msgtype": "m.file",
                "body": message or os.path.basename(file_path),
                "info": {"mimetype": msgtype},
                "url": upload_result["content_uri"],
            },
        )
        logger.info("Uploaded %s to %s: %s", file_path, room_id, event_id)
        return event_id

    def send_audio(
        self,
        audio_path: str,
        room_id: str,
        caption: str = "",
    ) -> str:
        """Send an audio file to a Matrix room."""
        return self.upload_media(
            audio_path,
            room_id,
            message=caption or "Audio file",
            msgtype="audio/ogg",
        )

    def send_pdf(
        self,
        pdf_path: str,
        room_id: str,
        caption: str = "",
    ) -> str:
        """Send a PDF file to a Matrix room."""
        return self.upload_media(
            pdf_path,
            room_id,
            message=caption or "PDF document",
            msgtype="application/pdf",
        )
```

import os
from bot.media_uploader import MediaUploader

class TestMediaUploader:

## Граничные случаи
- **Файл не существует**: raises `FileNotFoundError`
- **Неизвестное расширение**: MIME = `application/octet-stream`
- **Пустой caption**: filename используется как body
- **Пустой файл**: загружается (0 байт)
- **Большой файл**: читается в память целиком (ограничение для больших файлов)
- **Множественные расширения**: `.tar.gz` — берётся последнее
