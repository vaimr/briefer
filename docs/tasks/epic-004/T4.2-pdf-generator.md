# T4.2: PDF генерация через Pandoc + WeasyPrint

## Описание
Модуль `worker/pdf_generator.py` — генерация PDF из текста транскрипции + саммари через Pandoc (Markdown → LaTeX → PDF).

**Эпик:** EPIC-004 (Worker LLM PDF)  
**Зависимости:** T4.1 (LLM client), T1.4 (Config module)  
**Оценка:** ~2 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Транскрипция + саммари | Markdown → LaTeX → PDF | PDF-файл в `data/` |

---

## Критерии приёмки

- [ ] `worker/pdf_generator.py` — класс `PDFGenerator` с методом:
  - `generate(transcription: str, summary: str, output_path: Path) -> Path`
- [ ] Pandoc используется для Markdown → LaTeX → PDF
- [ ] WeasyPrint не нужен (Pandoc генерирует PDF напрямую)
- [ ] PDF содержит: заголовок, саммари, транскрипцию, timestamp
- [ ] Поддержка Cyrillic в PDF (шрифт lmodern)
- [ ] PDF валидный (открывается в PDF viewer)

---

## Граничные случаи

- Pandoc недоступен — ValueError
- LaTeX недоступен — ValueError
- Текст транскрипции слишком длинный (> 50000 символов) — truncate
- Саммари пустое — пропустить секцию саммари
- Шрифт Cyrillic не найден — fallback на monospace
- Pandoc возвращает ошибку — ValueError с stderr

## Пошаговый план

1. Создать `worker/pdf_generator.py`:
   ```python
   import logging
   import subprocess
   from datetime import datetime
   from pathlib import Path

   class PDFGenerator:
       MAX_TRANSCRIPTION_LENGTH = 50000

       def generate(self, transcription: str, summary: str, output_path: Path) -> Path:
           # truncate transcription
           if len(transcription) > self.MAX_TRANSCRIPTION_LENGTH:
               transcription = transcription[:self.MAX_TRANSCRIPTION_LENGTH]

           # создать markdown
           markdown = self._create_markdown(transcription, summary)
           markdown_path = output_path.with_suffix(".md")
           markdown_path.write_text(markdown, encoding="utf-8")

           # pandoc: markdown → pdf
           cmd = [
               "pandoc",
               str(markdown_path),
               "-o", str(output_path),
               "--pdf-engine=xelatex",
               "-V", "mainfont=lmodern",
               "-V", "fontsize=12pt",
               "-V", "geometry:margin=1in",
           ]

           result = subprocess.run(cmd, capture_output=True, text=True)
           if result.returncode != 0:
               raise ValueError(f"Pandoc failed: {result.stderr}")

           # удалить markdown
           markdown_path.unlink()

           return output_path

       def _create_markdown(self, transcription: str, summary: str) -> str:
           timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
           md = f"# Транскрипция\n\n"
           md += f"_Дата: {timestamp}_\n\n"

           if summary and summary != "Нет данных для саммари":
               md += "## Саммари\n\n"
               md += f"{summary}\n\n"
               md += "---\n\n"

           md += "## Транскрипция\n\n"
           md += transcription

           return md
   ```
