# T4.4 — End-to-End Summary Pipeline

## Описание

Реализовать финальный пайплайн воркера: получение транскрипции → LLM summary → PDF generation → сохранение результата.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Транскрипция | LLM summary → Markdown → PDF → сохранение | PDF файл готов |

## Критерии приёмки
- [ ] `worker/pipeline.py` — функция `process_transcription(transcript) → Path`
- [ ] Вызывает `llm_engine.summarize(transcript)` → summary
- [ ] Вызывает `pdf_generator.generate(summary) → Path`
- [ ] Сохраняет PDF в `data/summaries/`
- [ ] Логирование каждой стадии

## Граничные случаи
- Пустая транскрипция → ValueError
- LLM вернул пустой summary → ValueError
- PDF генерация не удалась → raise Exception
- `data/summaries/` не существует → создать

## Пошаговый план
1. Создать `worker/pipeline.py`
2. Реализовать `process_transcription()`
3. Написать тесты
4. Запустить тесты
