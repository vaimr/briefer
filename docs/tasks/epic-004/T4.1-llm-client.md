# T4.1: LLM API интеграция с retry

## Описание
Модуль `worker/llm_client.py` — вызов LLM API (OpenAI-compatible) для генерации саммари. Retry logic, timeout, error handling.

**Эпик:** EPIC-004 (Worker LLM PDF)  
**Зависимости:** T1.4 (Config module), T1.3 (Test framework)  
**Оценка:** ~2 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Текст транскрипции | Вызов LLM API → саммари | Текст саммари ≤ 2000 символов |

---

## Критерии приёмки

- [ ] `worker/llm_client.py` — класс `LLMClient` с методом:
  - `summarize(text: str) -> str` — генерирует саммари текста
- [ ] `requests>=2.31.0` добавлен в `worker/requirements.txt`
- [ ] Retry logic: 3 попытки, 2 секунды между попытками
- [ ] Timeout: 60 секунд на запрос
- [ ] OpenAI-compatible API формат (chat/completions)
- [ ] Саммари ≤ 2000 символов

---

## Граничные случаи

- API недоступен — retry 3 раза, затем ValueError
- API вернул 4xx — ValueError с сообщением об ошибке
- API вернул 5xx — retry
- Текст транскрипции > 4000 символов — truncate до 4000
- Текст транскрипции пустой — вернуть "Нет данных для саммари"
- API вернул пустой ответ — ValueError

## Пошаговый план

1. Добавить `requests>=2.31.0` в `worker/requirements.txt`

2. Создать `worker/llm_client.py`:
   ```python
   import logging
   import requests
   from bot.config import WorkerConfig

   class LLMClient:
       MAX_SUMMARY_LENGTH = 2000
       MAX_TRANSCRIPTION_LENGTH = 4000
       MAX_RETRIES = 3
       RETRY_DELAY = 2  # seconds
       REQUEST_TIMEOUT = 60  # seconds

       def __init__(self, config: WorkerConfig):
           self.api_url = config.llm_api_url
           self.model_name = config.llm_model_name
           self.headers = {"Content-Type": "application/json"}

       def summarize(self, transcription_text: str) -> str:
           if not transcription_text or not transcription_text.strip():
               return "Нет данных для саммари"

           # truncate если слишком длинный
           if len(transcription_text) > self.MAX_TRANSCRIPTION_LENGTH:
               transcription_text = transcription_text[:self.MAX_TRANSCRIPTION_LENGTH]

           payload = {
               "model": self.model_name,
               "messages": [
                   {"role": "system", "content": "Ты — ассистент для краткого изложения аудио-транскрипций."},
                   {"role": "user", "content": f"Сделай краткое саммари этого текста (до {self.MAX_SUMMARY_LENGTH} символов):\n\n{transcription_text}"},
               ],
               "max_tokens": 1500,
           }

           for attempt in range(self.MAX_RETRIES):
               try:
                   response = requests.post(
                       f"{self.api_url}/chat/completions",
                       json=payload,
                       headers=self.headers,
                       timeout=self.REQUEST_TIMEOUT,
                   )
                   response.raise_for_status()
                   data = response.json()
                   summary = data["choices"][0]["message"]["content"]
                   return summary[:self.MAX_SUMMARY_LENGTH]

               except requests.exceptions.HTTPError as e:
                   if response.status_code >= 500:
                       if attempt == self.MAX_RETRIES - 1:
                           raise
                   else:
                       raise ValueError(f"LLM API error: {e}") from e
               except requests.exceptions.ConnectionError:
                   if attempt == self.MAX_RETRIES - 1:
                       raise
                   logging.warning(f"Connection error, retrying... (attempt {attempt + 1})")
               except requests.exceptions.Timeout:
                   if attempt == self.MAX_RETRIES - 1:
                       raise
                   logging.warning(f"Timeout, retrying... (attempt {attempt + 1})")

               import asyncio
               await asyncio.sleep(self.RETRY_DELAY)
   ```
