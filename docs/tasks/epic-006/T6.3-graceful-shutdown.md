# T6.3: Graceful shutdown

## Описание
Модуль `worker/shutdown.py` — обработка SIGTERM/SIGINT для graceful shutdown worker и bot.

**Эпик:** EPIC-006 (Reliability Errors)  
**Зависимости:** T1.4 (Config module), T1.3 (Test framework)  
**Оценка:** ~1 час

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| SIGTERM/SIGINT | Graceful shutdown: завершить текущую задачу, выйти | Worker/bot завершается чистко |

---

## Критерии приёмки

- [ ] `worker/shutdown.py` — класс `GracefulShutdown` с методами:
  - `setup()` — регистрирует обработчики SIGTERM/SIGINT
  - `is_running()` — возвращает False если shutdown запрошен
  - `wait()` — блокирует до завершения текущей задачи
- [ ] Bot и Worker используют GracefulShutdown
- [ ] SIGTERM → завершить текущую задачу, выйти
- [ ] SIGINT → завершить текущую задачу, выйти

---

## Граничные случаи

- SIGTERM во время обработки задачи — завершить задачу, затем выйти
- SIGTERM во время ожидания blpop — выйти немедленно
- SIGTERM во время подключения к Redis — выйти немедленно
- Multiple SIGTERM — второй игнорируется

## Пошаговый план

1. Создать `worker/shutdown.py`:
   ```python
   import asyncio
   import logging
   import signal
   import threading

   class GracefulShutdown:
       def __init__(self):
           self._running = True
           self._shutdown_event = threading.Event()

       def setup(self) -> None:
           def handler(signum, frame):
               logging.info(f"Signal {signum} received, shutting down...")
               self._running = False
               self._shutdown_event.set()

           signal.signal(signal.SIGTERM, handler)
           signal.signal(signal.SIGINT, handler)

       @property
       def is_running(self) -> bool:
           return self._running

       def wait(self, timeout: float = 30.0) -> None:
           self._shutdown_event.wait(timeout=timeout)
   ```
