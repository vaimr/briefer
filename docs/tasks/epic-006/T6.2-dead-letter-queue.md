# T6.2: Dead Letter Queue

## Описание
Модуль `worker/dlq.py` — обработка упавших задач: запись в Redis `dlq:transcription` с metadata.

**Эпик:** EPIC-006 (Reliability Errors)  
**Зависимости:** T6.1 (Retry mechanism), T1.4 (Config module)  
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Упавшая задача | Запись в Redis `dlq:transcription` с metadata | Задача в DLQ с task_id, error, traceback, timestamp |

---

## Критерии приёмки

- [ ] `worker/dlq.py` — класс `DeadLetterQueue` с методами:
  - `add(task_id: str, error: Exception, traceback: str) -> None`
  - `get_all() -> list` — возвращает все задачи в DLQ
  - `remove(task_id: str) -> None` — удаляет задачу из DLQ
- [ ] Redis list `dlq:transcription`
- [ ] JSON-формат: `{task_id, error, traceback, timestamp}`

---

## Граничные случаи

- DLQ Redis недоступен — логгировать error, не падать
- Task_id пустой — ValueError
- Error пустой — ValueError
- DLQ слишком большой (> 10000 задач) — truncate oldest

---

## Пошаговый план

1. Создать `worker/dlq.py`:
   ```python
   import json
   import logging
   import traceback
   from datetime import datetime

   import redis

   class DeadLetterQueue:
       CHANNEL = "dlq:transcription"
       MAX_SIZE = 10000

       def __init__(self, redis_client: redis.Redis):
           self.redis = redis_client

       def add(self, task_id: str, error: Exception, tb: str) -> None:
           if not task_id:
               raise ValueError("task_id is required")
           if not error:
               raise ValueError("error is required")

           message = {
               "task_id": task_id,
               "error": str(error),
               "traceback": tb,
               "timestamp": datetime.now().isoformat(),
           }

           self.redis.rpush(self.CHANNEL, json.dumps(message))

           # truncate если слишком большой
           while self.redis.llen(self.CHANNEL) > self.MAX_SIZE:
               self.redis.lpop(self.CHANNEL)

       def get_all(self) -> list:
           messages = self.redis.lrange(self.CHANNEL, 0, -1)
           return [json.loads(m) for m in messages]

       def remove(self, task_id: str) -> None:
           messages = self.get_all()
           for i, msg in enumerate(messages):
               if msg["task_id"] == task_id:
                   self.redis.lset(self.CHANNEL, i, None)
                   self.redis.lrem(self.CHANNEL, 1, json.dumps(msg))
                   break
   ```
