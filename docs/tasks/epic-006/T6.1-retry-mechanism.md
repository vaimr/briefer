# T6.1: Retry механизм

## Описание
Модуль `worker/retry.py` — универсальный retry decorator с exponential backoff для worker-тасков.

**Эпик:** EPIC-006 (Reliability Errors)  
**Зависимости:** T1.4 (Config module), T1.3 (Test framework)  
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Функция, которая может упасть | Retry с exponential backoff | Функция вызывается до N раз с увеличением задержки |

---

## Критерии приёмки

- [ ] `worker/retry.py` — декоратор `@retry(max_retries=3, base_delay=1.0)`
- [ ] Exponential backoff: delay = base_delay * 2^attempt
- [ ] Retry только для transient errors (ConnectionError, TimeoutError)
- [ ] Не retry для permanent errors (ValueError, TypeError)
- [ ] Логгирование каждой попытки

---

## Граничные случаи

- Функция падает все N раз — ValueError с последней ошибкой
- Функция падает на 2-й попытке — 2-я попытка, затем успех
- Функция падает на 1-й попытке — 1-я попытка, затем 2-я с delay 1 сек
- Функция падает на 2-й попытке — 2-я попытка, затем 3-я с delay 2 сек

---

## Пошаговый план

1. Создать `worker/retry.py`:
   ```python
   import functools
   import logging
   import time
   from typing import Callable, Type

   TRANSIENT_ERRORS = (ConnectionError, TimeoutError, OSError)

   def retry(max_retries: int = 3, base_delay: float = 1.0):
       def decorator(func: Callable) -> Callable:
           @functools.wraps(func)
           def wrapper(*args, **kwargs):
               last_exception = None
               for attempt in range(max_retries):
                   try:
                       return func(*args, **kwargs)
                   except TRANSIENT_ERRORS as e:
                       last_exception = e
                       if attempt < max_retries - 1:
                           delay = base_delay * (2 ** attempt)
                           logging.warning(f"{func.__name__} failed (attempt {attempt + 1}), retrying in {delay}s: {e}")
                           time.sleep(delay)
                       else:
                           raise
                   except Exception as e:
                       raise

               raise last_exception
           return wrapper
       return decorator
   ```
