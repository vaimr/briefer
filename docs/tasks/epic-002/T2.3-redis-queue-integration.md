# T2.3 — Redis Task Queue Integration

## Описание

Реализовать producer и consumer для Redis-очереди задач. Producer помещает задачи в `transcription_queue`, consumer (воркер) извлекает и обрабатывает.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Команда `enqueue_task(room_id, audio_path)` | `rpush` в `transcription_queue` | Задача в очереди |
| Команда `dequeue_task()` | `blpop` из `transcription_queue` | `(room_id, audio_path)` или `None` |

## Критерии приёмки
- [ ] `bot/client.py` — функция `enqueue_task(room_id, audio_path)` → `int`
- [ ] Формат задачи: `f"{room_id}|{audio_path}"`
- [ ] `worker/__main__.py` — функция `dequeue_task()` → `tuple[str, str] | None`
- [ ] `blpop` с timeout=5s (не блокирует навсегда)
- [ ] При timeout → вернуть `None`
- [ ] При ошибке Redis → raise `ConnectionError`

## Граничные случаи
- `room_id` пустой → ValueError
- `audio_path` не существует → FileNotFoundError
- Redis недоступен → ConnectionError
- `blpop` timeout=5s → None
- Очередь пуста → None
