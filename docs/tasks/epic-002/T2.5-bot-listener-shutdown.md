# T2.5 — Bot Message Listener & Graceful Shutdown

## Описание

Реализовать основной цикл бота: слушает Matrix-события, обрабатывает аудио, отправляет в очередь, управляет graceful shutdown.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Matrix-событие | Тип → audio → download → validate → enqueue → status | Задача обработана |
| SIGTERM/SIGINT | Graceful shutdown | Sync loop остановлен |

## Критерии приёмки
- [ ] `bot/__main__.py` — основной цикл обработки
- [ ] Обработка `m.room.message` с audio вложениями
- [ ] Игнорирование текстовых сообщений
- [ ] `--help` флаг
- [ ] SIGTERM → graceful shutdown
- [ ] SIGINT → graceful shutdown
- [ ] Логирование каждой стадии пайплайна

## Граничные случаи
- Сообщение без вложений → ignore
- Вложение не аудио → error статус
- Ошибка enqueue → error статус
- SIGTERM во время операции → завершить, затем shutdown

## Пошаговый план
1. Обновить `bot/__main__.py`
2. Реализовать event callback
3. Реализовать SIGTERM/SIGINT handlers
4. Написать тесты
5. Запустить тесты
