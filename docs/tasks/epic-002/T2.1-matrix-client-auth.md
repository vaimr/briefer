  - `connect()` — login (password или token), join room

- [ ] `matrix_access_token` имеет приоритет над `matrix_password`
- [ ] `join_room()` — если комната уже существует — не падает

---

## Граничные случаи

- `matrix_access_token` vs `matrix_password` — token имеет приоритет
- Комната уже присоединена — `join_room()` не должна падать
- Невалидные credentials — `LoginError` → ValueError с понятным сообщением
- Homeserver недоступен — retry 3 раза, 2 секунды между попытками
- Room alias vs room ID — поддержка обоих форматов

## Пошаговый план

1. Добавить `matrix-nio>=0.23.0` в `bot/requirements.txt`

2. Создать `bot/matrix_client.py`:
   ```python
   import asyncio
   import logging
   from matrix_cli.client import AsyncClient
   from matrix_cli.login import LoginError
   from bot.config import BotConfig

   class MatrixClient:
       def __init__(self, config: BotConfig):
           self.config = config
           self.client = AsyncClient(
               homeserver=config.matrix_homeserver,
               user_id=config.matrix_user,
           )
           self.room_id: str | None = None
           self._ready = False

       async def connect(self) -> None:
           for attempt in range(3):
               try:
                   if self.config.matrix_access_token:
                       await self.client.set_access_token(self.config.matrix_access_token)
                   elif self.config.matrix_password:
                       await self.client.login(
                           password=self.config.matrix_password,
                           store=True,
                       )
                   else:
                       raise ValueError("Either MATRIX_PASSWORD or MATRIX_ACCESS_TOKEN must be set")

                   self.room_id = await self.client.get_room_id_or_alias(
                       self.config.matrix_room_alias  # если есть
                   )
                   if not self.room_id:
                       # создать или присоединиться к комнате
                       pass

                   self._ready = True
                   return
               except (LoginError, ConnectionError) as e:
                   if attempt == 2:
                       raise
                   await asyncio.sleep(2)

       def is_connected(self) -> bool:
           return self._ready

       @property
       def room_id(self) -> str | None:
           return self.room_id
   ```
