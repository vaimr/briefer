# T2.2: Скачивание и валидация аудио

## Описание
Модуль `bot/audio_downloader.py` — прослушивание room, скачивание аудио-сообщений, валидация формата, отправка в Redis-очередь.

**Эпик:** EPIC-002 (Bot Matrix Audio)  
**Зависимости:** T2.1 (Matrix client), T1.4 (Config module)  
**Оценка:** ~2 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Аудиосообщение из Matrix | Скачивание, валидация формата, отправка в Redis | Файл в `data/`, key в Redis `transcription_queue` |

---

## Критерии приёмки

- [ ] `bot/audio_downloader.py` — класс `AudioDownloader` с методами:
  - `download_audio(message)` — скачивает файл из сообщения
  - `validate_audio(file_path)` — проверяет формат (wav/mp3/flac), длительность 3с–30мин
  - `send_to_queue(file_path)` — rpush в `transcription_queue`
- [ ] Поддерживаемые форматы: WAV, MP3, FLAC
- [ ] Минимальная длительность: 3 секунды
- [ ] Максимальная длительность: 30 минут
- [ ] Файлы сохраняются в `data/` по пути: `data/{room_id}/{message_id}.{ext}`
- [ ] Redis key формат: `{room_id}:{message_id}`

---

## Граничные случаи

- Неаудио сообщение (текст, картинка) — игнорировать
- Поддерживаемый формат (wav/mp3/flac) — обрабатывать
- Неподдерживаемый формат (ogg, webm) — логировать warning, пропускать
- Длительность < 3 секунд — логировать warning, пропускать
- Длительность > 30 минут — логировать warning, пропускать
- Файл > 50MB — логировать error, пропускать
- Room ID не существует — ValueError
- Redis недоступен — логировать error, не падать

   import os
   import subprocess
   import logging
   from pathlib import Path
   from bot.config import BotConfig

   class AudioDownloader:
       SUPPORTED_FORMATS = {".wav", ".mp3", ".flac"}
       MIN_DURATION = 3  # seconds
       MAX_DURATION = 30 * 60  # 30 minutes
       MAX_FILE_SIZE = 50 * 1024 * 1024  # 50 MB

       def __init__(self, config: BotConfig, data_dir: str = "/data"):
           self.config = config
           self.data_dir = Path(data_dir)
           self.data_dir.mkdir(parents=True, exist_ok=True)

       async def download_audio(self, message) -> Path:
           room_id = message.room_id
           message_id = message.message_id
           file_url = message.content.body  # или через API matrix-nio

           # скачать файл
           file_path = self.data_dir / room_id / f"{message_id}.wav"
           file_path.parent.mkdir(parents=True, exist_ok=True)

           # получить формат из URL или расширения
           ext = self._get_extension(file_url)
           file_path = file_path.with_suffix(ext)

           return file_path

       def validate_audio(self, file_path: Path) -> bool:
           # проверить размер
           if file_path.stat().st_size > self.MAX_FILE_SIZE:
               logging.warning(f"File {file_path} too large")
               return False

           # проверить формат
           if file_path.suffix.lower() not in self.SUPPORTED_FORMATS:
               logging.warning(f"Unsupported format: {file_path.suffix}")
               return False

           # проверить длительность через ffprobe
           duration = self._get_duration(file_path)
           if duration < self.MIN_DURATION:
               logging.warning(f"File {file_path} too short: {duration}s")
               return False
           if duration > self.MAX_DURATION:
               logging.warning(f"File {file_path} too long: {duration}s")
               return False

           return True

       def send_to_queue(self, file_path: Path) -> str:
           room_id = file_path.parent.name
           message_id = file_path.stem
           key = f"{room_id}:{message_id}"
