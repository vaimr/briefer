# T2.4 — Status Notifications

## Описание

Реализовать модуль статусных уведомлений. Бот отправляет статусные сообщения в Matrix-комнату: processing, done, error.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| room_id, status, message | Формирование сообщения → `room_send` | Статус отправлен |

## Критерии приёмки
- [ ] `bot/notifications.py` — функция `send_status(room_id, status, message)` → None
- [ ] Статусы: `processing` → `[⏳]`, `done` → `[✅]`, `error` → `[❌]`
- [ ] Формат: `[EMOJI] message`
- [ ] Сообщение ≤ 4000 символов (truncate)
- [ ] Статус не из списка → ValueError

## Граничные случаи
- Пустой status → ValueError
- Пустой room_id → ValueError
- Сообщение > 4000 символов → truncate
- Ошибка отправки → log error, не raise
