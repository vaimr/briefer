# T5.2: Загрузка PDF в Matrix

## Описание
Модуль `bot/pdf_uploader.py` — загрузка PDF-файла в Matrix как сообщение с attachment.

**Эпик:** EPIC-005 (Bot Result Delivery)  
**Зависимости:** T5.1 (Result listener), T2.1 (Matrix client), T1.4 (Config module)  
**Оценка:** ~2 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| PDF-файл | Загрузка в Matrix как m.file | Сообщение с PDF attachment в room |

---

## Критерии приёмки

- [ ] `bot/pdf_uploader.py` — класс `PDFUploader` с методом:
  - `upload(room_id: str, pdf_path: Path, task_id: str) -> str` — возвращает event_id
- [ ] Matrix `m.file` event тип
- [ ] PDF файл ≤ 50MB
- [ ] Event ID возвращается после успешной загрузки
- [ ] `matrix-nio>=0.23.0` добавлен в `bot/requirements.txt`

---

## Граничные случаи

- PDF файл > 50MB — ValueError
- PDF файл не найден — FileNotFoundError
- Room ID не существует — ValueError
- Matrix API недоступен — retry 3 раза
- Matrix API вернул ошибку — ValueError

---

## Пошаговый план

1. Создать `bot/pdf_uploader.py`:
   ```python
   import logging
   from pathlib import Path

   class PDFUploader:
       MAX_FILE_SIZE = 50 * 1024 * 1024  # 50 MB

       def __init__(self, client):
           self.client = client

       def upload(self, room_id: str, pdf_path: Path, task_id: str) -> str:
           if not pdf_path.exists():
               raise FileNotFoundError(f"PDF not found: {pdf_path}")
           if pdf_path.stat().st_size > self.MAX_FILE_SIZE:
               raise ValueError(f"PDF too large: {pdf_path.stat().st_size} bytes")

           with open(pdf_path, "rb") as f:
               file_data = f.read()

           # upload через matrix-nio
           content_uri = self.client.upload(
               file_data,
               content_type="application/pdf",
               filename=f"{task_id}.pdf",
           )

           # отправить сообщение с attachment
           event_id = self.client.api.send_message(
               room_id,
               "m.room.message",
               {
                   "msgtype": "m.file",
                   "body": f"{task_id}.pdf",
                   "url": content_uri,
                   "info": {
                       "mimetype": "application/pdf",
                       "size": pdf_path.stat().st_size,
                   },
               },
           )

           return event_id
   ```
