# T5.1: Redis pub/sub listener

## Описание
Модуль `bot/result_listener.py` — прослушивание Redis pub/sub канала `task_results`, парсинг JSON, вызов обработчиков.

**Эпик:** EPIC-005 (Bot Result Delivery)  
**Зависимости:** T1.4 (Config module), T1.3 (Test framework)  
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Redis pub/sub `task_results` | Парсинг JSON, вызов обработчиков | Обработчик получает результат задачи |

---

## Критерии приёмки

- [ ] `bot/result_listener.py` — класс `ResultListener` с методом:
  - `listen(callback)` — слушает канал `task_results`, вызывает callback для каждого сообщения
- [ ] Redis pub/sub канал `task_results`
- [ ] JSON-парсинг с fallback на error-обработку
- [ ] `redis>=5.0.0` добавлен в `bot/requirements.txt`

---

## Граничные случаи

- Redis недоступен — retry каждые 5 секунд
- JSON parse error — логгировать error, продолжить слушать
- Сообщение не содержит task_id — логгировать error, продолжить слушать
- callback упал — логгировать error, продолжить слушать
- SIGTERM — graceful shutdown

## Пошаговый план

1. Добавить `redis>=5.0.0` в `bot/requirements.txt`

2. Создать `bot/result_listener.py`:
   ```python
   import json
   import logging
   import signal
   from bot.config import BotConfig

   class ResultListener:
       CHANNEL = "task_results"

       def __init__(self, config: BotConfig):
           self.config = config
           self._running = False

       def listen(self, callback) -> None:
           import redis
           self._running = True
           r = redis.Redis(
               host=self.config.redis_host,
               port=self.config.redis_port,
               decode_responses=True,
           )
           pubsub = r.pubsub()
           pubsub.subscribe(self.CHANNEL)

           def handle_sigterm(signum, frame):
               self._running = False

           signal.signal(signal.SIGTERM, handle_sigterm)
           signal.signal(signal.SIGINT, handle_sigterm)

           while self._running:
               message = pubsub.get_message(ignore_subscribe_messages=True, timeout=1.0)
               if message and message["type"] == "message":
                   try:
                       data = json.loads(message["data"])
                       callback(data)
                   except json.JSONDecodeError as e:
                       logging.error(f"JSON parse error: {e}")
                   except Exception as e:
                       logging.error(f"Callback error: {e}")

           pubsub.unsubscribe(self.CHANNEL)
           pubsub.close()
   ```
