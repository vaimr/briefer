# T5.4 — Bot Graceful Shutdown for Result Consumer

## Описание

Реализовать graceful shutdown result consumer'а бота. При SIGTERM — завершить текущую операцию доставки, затем остановить.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| SIGTERM/SIGINT | Завершить текущую операцию → остановить consumer | Shutdown выполнен |

## Критерии приёмки
- [ ] `bot/__main__.py` — SIGTERM handler для result consumer
- [ ] Текущая операция доставки завершается (не прерывается)
- [ ] После завершения — stop sync loop
- [ ] Лог: `logger.info("Shutting down...")`

## Граничные случаи
- SIGTERM во время доставки → дождаться завершения
- SIGTERM без запущенного consumer → no-op
- Несколько SIGTERM → только первый обрабатывается

## Пошаговый план
1. Обновить `bot/__main__.py`
2. Добавить SIGTERM handler
3. Написать тесты
4. Запустить тесты
