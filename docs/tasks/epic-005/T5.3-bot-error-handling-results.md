# T5.3 — Bot Error Handling for Result Delivery

## Описание

Реализовать обработку ошибок при доставке результатов ботом. Если PDF не удалось загрузить в Matrix — retry + error статус.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Ошибка загрузки PDF | Retry (3 раза, backoff) → error статус | Ошибка обработана |

## Критерии приёмки
- [ ] `bot/result_consumer.py` — функция `deliver_result(room_id, pdf_path)` → None
- [ ] Retry 3 раза при ошибке upload
- [ ] Backoff: 1s, 2s, 4s
- [ ] После 3 неудач → error статус в комнату
- [ ] Логирование каждой попытки

## Граничные случаи
- PDF не существует → ValueError
- Matrix недоступен → retry
- Room недоступен → retry
- После 3 retry → error статус

## Пошаговый план
1. Создать `bot/result_consumer.py`
2. Реализовать `deliver_result()` с retry
3. Написать тесты
4. Запустить тесты
