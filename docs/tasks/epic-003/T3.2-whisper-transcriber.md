# T3.2: Whisper транскрипция

## Описание
Модуль `worker/transcriber.py` — вызов `faster_whisper` для транскрипции 16kHz mono WAV файлов.

**Эпик:** EPIC-003 (Worker Audio Transcription)  
**Зависимости:** T3.1 (Audio converter), T1.4 (Config module)  
**Оценка:** ~2 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| 16kHz mono WAV файл | Транскрипция через faster_whisper | Текст транскрипции, timestamp, confidence |

---

## Критерии приёмки

- [ ] `worker/transcriber.py` — класс `Transcriber` с методом:
  - `transcribe(file_path: Path) -> dict` — возвращает `{text, segments, duration}`
- [ ] `faster_whisper` используется для транскрипции
- [ ] Модель `large-v3` (int8, CPU) предзагружена
- [ ] Результат содержит: `text` (str), `segments` (list), `duration` (float)
- [ ] Транскрипция < 5 минут для 3-минутного файла
- [ ] `faster_whisper>=1.0.0` добавлен в `worker/requirements.txt`

---

## Граничные случаи

- Тихий файл (< 5% энергии) — `text` = ""
- Файл > 30 минут — ValueError
- Файл не 16kHz — ValueError (должен быть конвертирован в T3.1)
- Модель не загружена — ValueError
- Файл повреждён — ValueError
- GPU недоступен — fallback на CPU (int8 quantization)
- Пустой файл (0 секунд) — ValueError

## Пошаговый план

1. Добавить `faster_whisper>=1.0.0` в `worker/requirements.txt`

2. Создать `worker/transcriber.py`:
   ```python
   import logging
   from pathlib import Path
   from faster_whisper import WhisperModel

   class Transcriber:
       def __init__(self, model_name: str = "large-v3", device: str = "cpu"):
           self.model_name = model_name
           self.device = device
           self.model = WhisperModel(
               model_name,
               device=device,
               compute_type="int8",
           )

       def transcribe(self, file_path: Path) -> dict:
           if not file_path.exists():
               raise FileNotFoundError(f"File not found: {file_path}")

           duration = self._get_duration(file_path)
           if duration > 30 * 60:
               raise ValueError(f"File too long: {duration}s > 30min")
           if duration == 0:
               raise ValueError("Empty file")

           segments, info = self.model.transcribe(
               str(file_path),
               language="ru",
               beam_size=5,
           )

           text = "".join(seg.text for seg in segments)
           return {
               "text": text.strip(),
               "segments": [
                   {"text": seg.text, "start": seg.start, "end": seg.end}
                   for seg in segments
               ],
               "duration": duration,
               "language": info.language,
           }

       def _get_duration(self, file_path: Path) -> float:
           import wave
           with wave.open(str(file_path), "rb") as wf:
               return wf.getnframes() / wf.getframerate()
   ```
