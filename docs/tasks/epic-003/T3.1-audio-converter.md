# T3.1: Конвертация аудио через ffmpeg

## Описание
Модуль `worker/audio_converter.py` — конвертация любых поддерживаемых форматов в 16kHz mono WAV для Whisper.

**Эпик:** EPIC-003 (Worker Audio Transcription)  
**Зависимости:** T1.3 (Test framework), T1.4 (Config module)  
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| WAV/MP3/FLAC файл | Конвертация через ffmpeg → 16kHz mono WAV | Валидный WAV-файл, duration сохранена |

---

## Критерии приёмки

- [ ] `worker/audio_converter.py` — класс `AudioConverter` с методом:
  - `convert(input_path: Path) -> Path` — конвертирует в 16kHz mono WAV
- [ ] Поддерживаемые форматы: WAV, MP3, FLAC
- [ ] Выходной формат: 16kHz mono WAV
- [ ] `ffmpeg` доступен в Docker-образе worker
- [ ] Конвертация < 30 секунд для 3-минутного файла
- [ ] Выходной WAV валидный (проверяется через `wave` модуль)

---

## Граничные случаи

- WAV уже 16kHz mono — не конвертировать, вернуть как есть
- WAV 48kHz stereo — конвертировать в 16kHz mono
- MP3 44.1kHz stereo — конвертировать в 16kHz mono
- FLAC 24kHz mono — конвертировать в 16kHz mono
- Неподдерживаемый формат — ValueError
- Файл повреждён — ValueError
- ffmpeg недоступен — ValueError с понятным сообщением

## Пошаговый план

1. Создать `worker/audio_converter.py`:
   ```python
   import subprocess
   import logging
   from pathlib import Path
   import wave

   class AudioConverter:
       SUPPORTED_FORMATS = {".wav", ".mp3", ".flac"}
       OUTPUT_SAMPLE_RATE = 16000
       OUTPUT_CHANNELS = 1

       def convert(self, input_path: Path) -> Path:
           if input_path.suffix.lower() not in self.SUPPORTED_FORMATS:
               raise ValueError(f"Unsupported format: {input_path.suffix}")

           output_path = input_path.with_suffix(".wav")

           # проверить если уже 16kHz mono WAV
           if self._is_already_optimal(input_path):
               return input_path

           # конвертировать через ffmpeg
           cmd = [
               "ffmpeg", "-y",
               "-i", str(input_path),
               "-ar", str(self.OUTPUT_SAMPLE_RATE),
               "-ac", str(self.OUTPUT_CHANNELS),
               "-c:a", "pcm_s16le",
               str(output_path),
           ]

           result = subprocess.run(cmd, capture_output=True, text=True)
           if result.returncode != 0:
               raise ValueError(f"ffmpeg failed: {result.stderr}")

           # проверить что выход валидный
           self._validate_wav(output_path)
           return output_path

       def _is_already_optimal(self, path: Path) -> bool:
           if path.suffix.lower() != ".wav":
               return False
           with wave.open(str(path), "rb") as wf:
               if wf.getframerate() != self.OUTPUT_SAMPLE_RATE:
                   return False
               if wf.getnchannels() != self.OUTPUT_CHANNELS:
                   return False
           return True

       def _validate_wav(self, path: Path) -> None:
           with wave.open(str(path), "rb") as wf:
               assert wf.getframerate() == self.OUTPUT_SAMPLE_RATE
               assert wf.getnchannels() == self.OUTPUT_CHANNELS
   ```
