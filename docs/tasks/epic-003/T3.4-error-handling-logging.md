# T3.4 — Error Handling & Logging

## Описание

Реализовать модуль обработки ошибок и логирования для воркера. Логирование в JSON формате, обработка исключений в pipeline.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Исключение в pipeline | Логирование → retry → DLQ (если max retries) | Ошибка обработана |

## Критерии приёмки
- [ ] `worker/errors.py` — класс `TaskError` с полями: `task_id`, `error_type`, `message`, `retry_count`
- [ ] `worker/errors.py` — функция `handle_error(task_id, error, max_retries)` → bool (retry?)
- [ ] Логирование в JSON формате (structlog или json.dumps)
- [ ] Retry count увеличивается при каждом повторе
- [ ] При max_retries → task в DLQ

## Граничные случаи
- `retry_count=0` → retry
- `retry_count=max_retries` → DLQ
- `error=None` → raise ValueError
- `max_retries < 0` → raise ValueError
