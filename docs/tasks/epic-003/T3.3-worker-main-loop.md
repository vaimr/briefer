# T3.3: Worker main — blpop loop и orchestration

## Описание
Модуль `worker/main.py` — основной цикл worker: `blpop` из Redis, orchestration конвертации → транскрипции → отправки результата.

**Эпик:** EPIC-003 (Worker Audio Transcription)  
**Зависимости:** T3.1 (Audio converter), T3.2 (Whisper transcriber), T1.4 (Config module)  
**Оценка:** ~2 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Redis queue `transcription_queue` | Worker обрабатывает задачи: конвертация → транскрипция → результат | Результат транскрипции отправляется в Redis `task_results` pub/sub |

---

## Критерии приёмки

- [ ] `worker/main.py` — основной цикл:
  - `blpop("transcription_queue", timeout=30)`
  - Для каждой задачи: конвертация → транскрипция → отправка результата
  - Graceful shutdown при SIGTERM
- [ ] `worker/requirements.txt` содержит: `redis>=5.0.0`
- [ ] Worker не падает при ошибке — логгирует и переходит к следующей задаче
- [ ] Каждая задача обрабатывается в отдельном контексте (cleanup после каждой)

---

## Граничные случаи

- Redis недоступен — retry каждые 5 секунд
- Задача повреждена (файл не найден) — логгировать error, перейти к следующей
- Транскрипция упала — логгировать error, перейти к следующей
- SIGTERM — graceful shutdown: завершить текущую задачу, выйти
- Пустая очередь — `blpop` timeout 30 секунд, loop продолжается

## Пошаговый план

1. Создать `worker/main.py`:
   ```python
   import asyncio
   import logging
   import signal
   import sys
   from pathlib import Path

   from bot.config import WorkerConfig
   from worker.audio_converter import AudioConverter
   from worker.transcriber import Transcriber
   from worker.result_publisher import ResultPublisher  # из T4.3

   def main():
       config = WorkerConfig()
       converter = AudioConverter()
       transcriber = Transcriber(model_name=config.whisper_model)
       publisher = ResultPublisher(config)

       running = True

       def handle_sigterm(signum, frame):
           nonlocal running
           logging.info("SIGTERM received, shutting down...")
           running = False

       signal.signal(signal.SIGTERM, handle_sigterm)
       signal.signal(signal.SIGINT, handle_sigterm)

       logging.info("Worker started, listening on transcription_queue...")

       while running:
           try:
               # blpop из очереди
               result = publisher.redis.blpop("transcription_queue", timeout=30)
               if result is None:
                   continue

               key = result[1].decode()
               logging.info(f"Processing task: {key}")

               room_id, message_id = key.split(":")
               input_path = Path(config.data_dir) / room_id / f"{message_id}.mp3"  # или другой формат

               # конвертация
               wav_path = converter.convert(input_path)

               # транскрипция
               transcription = transcriber.transcribe(wav_path)

               # отправка результата
               publisher.publish_result(key, transcription)

               logging.info(f"Task {key} completed")

           except Exception as e:
               logging.error(f"Task failed: {e}")
               continue

       logging.info("Worker stopped")
   ```
