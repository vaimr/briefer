# T7.2: Health check endpoints

## Описание
Модуль `bot/health.py` и `worker/health.py` — HTTP health check endpoints (port 8080 для bot, 8081 для worker).

**Эпик:** EPIC-007 (Observability Config)
**Зависимости:** T1.4 (Config module), T1.3 (Test framework)
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| HTTP GET /health | Проверка Redis, Matrix (bot), Whisper (worker) | JSON с status: "healthy", "degraded", "unhealthy" |

---

## Критерии приёмки

- [ ] `bot/health.py` — HTTP server на port 8080:
  - `GET /health` — возвращает `{status, checks: {redis, matrix}}`
- [ ] `worker/health.py` — HTTP server на port 8081:
  - `GET /health` — возвращает `{status, checks: {redis, whisper, llm}}`
- [ ] `status: "healthy"` — все проверки успешны
- [ ] `status: "degraded"` — часть проверок упала
- [ ] `status: "unhealthy"` — все проверки упали
- [ ] `flask>=2.0.0` или `http.server` встроенный

---

## Граничные случаи

- Redis недоступен — check fails
- Matrix недоступен (только bot) — check fails
- Whisper не загружен (только worker) — check fails
- LLM API недоступен (только worker) — check fails
- 1 check fails → "degraded"
- 2+ checks fail → "unhealthy"
- Все checks pass → "healthy"

## Пошаговый план

1. Создать `bot/health.py`:
   ```python
   import json
   import logging
   from http.server import HTTPServer, BaseHTTPRequestHandler
   import redis

   class HealthHandler(BaseHTTPRequestHandler):
       def do_GET(self):
           if self.path == "/health":
               checks = {}

               # check redis
               try:
                   r = redis.Redis(host="redis", port=6379)
                   r.ping()
                   checks["redis"] = "healthy"
               except Exception:
                   checks["redis"] = "unhealthy"

               # check matrix
               try:
                   # проверить что client подключён
                   checks["matrix"] = "healthy"
               except Exception:
                   checks["matrix"] = "unhealthy"

               # determine status
               statuses = list(checks.values())
               if all(s == "healthy" for s in statuses):
                   status = "healthy"
               elif any(s == "unhealthy" for s in statuses):
                   status = "unhealthy"
               else:
                   status = "degraded"

               response = json.dumps({"status": status, "checks": checks})
               self.send_response(200)
               self.send_header("Content-Type", "application/json")
               self.end_headers()
               self.wfile.write(response.encode())
           else:
               self.send_response(404)
               self.end_headers()

   def start_health_server(port: int = 8080) -> HTTPServer:
       server = HTTPServer(("0.0.0.0", port), HealthHandler)
       server.serve_forever()
   ```

2. Создать `worker/health.py` — аналогично с checks: redis, whisper, llm

3. Написать тесты (см. ниже)
