# T7.1 — JSON Structured Logging

## Описание

Реализовать JSON-логгер для бота и воркера. Все логи в формате JSON для парсинга в ELK/Grafana.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| logger.info/error/debug | JSON-строка с timestamp, level, message, fields | JSON лог в stdout |

## Критерии приёмки
- [ ] `bot/logging.py` — функция `setup_logging(level="INFO") → None`
- [ ] `worker/logging.py` — аналогично
- [ ] Формат: `{"timestamp": "...", "level": "...", "message": "...", "service": "bot/worker"}`
- [ ] Логи в stdout (не в файл)
- [ ] Поддержка уровней: DEBUG, INFO, WARNING, ERROR, CRITICAL

## Граничные случаи
- `level` не из списка → ValueError
- `level` пустой → default INFO
- stdout не доступен → fallback to stderr

## Пошаговый план
1. Создать `bot/logging.py` и `worker/logging.py`
2. Реализовать `setup_logging()`
3. Написать тесты
4. Запустить тесты
