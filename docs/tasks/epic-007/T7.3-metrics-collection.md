# T7.3 — Metrics Collection

## Описание

Реализовать сбор метрик: количество обработанных задач, ошибки, время обработки. Expose в формате Prometheus.

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| События в pipeline | Increment counters → histogram | Метрики доступны для Prometheus scrape |

## Критерии приёмки
- [ ] `bot/metrics.py` — метрики: `tasks_processed`, `tasks_failed`, `processing_duration`
- [ ] `worker/metrics.py` — аналогично
- [ ] Метрики в формате Prometheus
- [ ] Endpoint `/metrics` для scrape
- [ ] Counter: tasks_processed, tasks_failed
- [ ] Histogram: processing_duration (seconds)

## Граничные случаи
- Метрики не инициализированы → raise RuntimeError
- Prometheus не установлен → fallback to in-memory counters
- Duplicate metric names → raise ValueError

## Пошаговый план
1. Создать `bot/metrics.py` и `worker/metrics.py`
2. Реализовать counters и histograms
3. Написать тесты
4. Запустить тесты
