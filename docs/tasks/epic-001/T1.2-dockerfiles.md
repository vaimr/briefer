# T1.2: Docker Compose и Dockerfiles

## Описание
Multi-stage Docker-файлы для bot и worker, конфигурация `docker-compose.yml` с healthcheck, volumes, environment.

**Эпик:** EPIC-001 (Foundation)  
**Зависимости:** T1.1 (Directory structure)  
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Существующие `bot/bot.py`, `worker/worker.py` | Multi-stage Docker-файлы: stage 1 = build, stage 2 = runtime | `docker compose build` проходит; все 3 сервиса запускаются; размер образа минимизирован |

---

## Критерии приёмки

- [ ] `bot/Dockerfile` — multi-stage: `python:3.11-slim` → `COPY --from=builder`, CMD `python bot.py`
- [ ] `worker/Dockerfile` — multi-stage: `python:3.11-slim` → apt-get deps, `COPY --from=builder`, CMD `python worker.py`
- [ ] `docker-compose.yml` — 3 сервиса (redis, bot, worker), healthcheck для Redis, depends_on с condition, volumes, environment
- [ ] `docker compose build` завершается без ошибок
- [ ] `docker compose up -d redis && docker compose exec redis redis-cli ping` возвращает `PONG`
- [ ] Размер образа worker < 1.5 GB
- [ ] Размер образа bot < 500 MB

---

## Граничные случаи

- Multi-stage: builder stage должен иметь все build-зависимости, runtime stage — только runtime
- Модель Whisper должна быть предзагружена в Dockerfile
- `extra_hosts` для `faex:host-gateway` — проверка что хост доступен
- Шрифты для Cyrillic PDF должны быть в runtime stage (lmodern, texlive-fonts-recommended, fonts-liberation)
- `--no-install-recommends` для apt-get — минимизация размера образа

---

## Пошаговый план

1. Обновить `bot/Dockerfile` в multi-stage формате:
   ```dockerfile
   # Stage 1: Build dependencies
   FROM python:3.11-slim AS builder
   WORKDIR /app
   COPY requirements.txt .
   RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

   # Stage 2: Runtime
   FROM python:3.11-slim
   COPY --from=builder /install /usr/local
   WORKDIR /app
   COPY bot/ .
   CMD ["python", "bot.py"]
   ```

2. Обновить `worker/Dockerfile` в multi-stage формате:
   ```dockerfile
   # Stage 1: Build dependencies
   FROM python:3.11-slim AS builder
   WORKDIR /app
   COPY requirements.txt .
   RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

   # Stage 2: Runtime
   FROM python:3.11-slim
   RUN apt-get update && apt-get install -y --no-install-recommends \
       ffmpeg \
       pandoc \
       texlive-latex-recommended \
       texlive-latex-extra \
       texlive-fonts-recommended \
       lmodern \
       fonts-liberation \
       && rm -rf /var/lib/apt/lists/*

   COPY --from=builder /install /usr/local
   WORKDIR /app
   COPY worker/ .
   CMD ["python", "worker.py"]
   ```

3. Проверить `docker-compose.yml` — все переменные, volumes, healthcheck
4. Запустить `docker compose build --no-cache`
5. Запустить `docker compose up -d redis` и проверить healthcheck
6. Проверить размеры образов: `docker images`
