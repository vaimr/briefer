## Описание
Настройка pytest, pytest-asyncio, pytest-mock, pytest-cov. Создание conftest.py с fixtures для Redis, Matrix, файлов. Тестовые аудиофайлы.

**Эпик:** EPIC-001 (Foundation)  
**Зависимости:** T1.1 (Directory structure)  
**Оценка:** ~2 часа

| Input | Обработка | Output |
|-------|-----------|--------|
| pytest, pytest-asyncio, pytest-mock | Настройка conftest.py с fixtures для Redis, Matrix, файлов | Тесты могут мокировать Redis, Matrix Client, создавать тестовые аудиофайлы |

---

## Критерии приёмки

- [ ] `tests/requirements-dev.txt` содержит: `pytest>=8.0`, `pytest-asyncio>=0.23`, `pytest-mock>=3.14`, `pytest-cov>=5.0`, `pydub>=0.25`, `pytest-timeout>=2.3`
- [ ] `tests/conftest.py` содержит fixtures:
  - `redis_mock()` — мокирует Redis с методами `rpush`, `blpop`, `publish`, `pubsub`
  - `temp_audio_wav(tmp_path)` — генерирует 1-секундный WAV-файл
  - `temp_dir(tmp_path)` — возвращает `tmp_path`
  - `matrix_client_mock(mocker)` — мокает `AsyncClient`
- [ ] `pytest --collect-only` находит все fixtures
- [ ] Пустой тест проходит (`assert True`)
- [ ] `tests/fixtures/` содержит минимум 3 тестовых аудиофайла:
  - `short.wav` — ~3 секунды, 16kHz mono WAV
  - `medium.mp3` — ~30 секунд, 44.1kHz stereo MP3
  - `long.flac` — ~3 минуты, 16kHz mono FLAC
- [ ] `pytest-asyncio` mode = "auto"

---

## Граничные случаи

- `pytest-asyncio` mode = "auto" для async-тестов
- Fixtures должны быть изолированы — каждая тестовая функция получает свежий мокированный Redis
- Файл `temp_audio_wav()` должен быть валидным WAV (генерация через `pydub`)
- Реальные аудиофайлы должны быть валидными (проверить через `ffmpeg -i`)
- Файлы должны покрывать разные sample rates и каналы

## Пошаговый план

1. Создать `tests/requirements-dev.txt`:
   ```
   pytest>=8.0
   pytest-asyncio>=0.23
   pytest-mock>=3.14
   pytest-cov>=5.0
   pydub>=0.25
   pytest-timeout>=2.3
   ```

2. Создать `tests/conftest.py`:
   - Импорт: `pytest_mock`, `tempfile`, `pathlib`, `pydub`
   - `@pytest.fixture def redis_mock(mocker)` — создаёт `MockRedis` с методами `rpush`, `blpop`, `publish`, `pubsub`
   - `@pytest.fixture def temp_audio_wav(tmp_path)` — генерирует 1-секундный WAV-файл через `pydub`
   - `@pytest.fixture def temp_dir(tmp_path)` — возвращает `tmp_path`
   - `@pytest.fixture def matrix_client_mock(mocker)` — мокает `AsyncClient`
   - Добавить `pytest.ini` или `pyproject.toml` с `asyncio_mode = auto`

3. Создать `tests/unit/__init__.py` и `tests/integration/__init__.py`

4. Создать тестовые аудиофайлы через `pydub`:
   ```python
   from pydub import AudioSegment
   # short.wav: 3 секунды, 16kHz, mono
   audio = AudioSegment.silent(duration=3000, frame_rate=16000)
   audio = audio.set_channels(1)
   audio.export("tests/fixtures/short.wav", format="wav")
   # medium.mp3: 30 секунд, 44.1kHz, stereo
   audio = AudioSegment.silent(duration=30000, frame_rate=44100)
   audio.export("tests/fixtures/medium.mp3", format="mp3")
   # long.flac: 3 минуты, 16kHz, mono
   audio = AudioSegment.silent(duration=180000, frame_rate=16000)
   audio = audio.set_channels(1)
   audio.export("tests/fixtures/long.flac", format="flac")
   ```

5. Создать `tests/test_placeholder.py` с `assert True`
6. Создать `tests/pytest.ini`:
   ```ini
   [pytest]
   asyncio_mode = auto
   testpaths = tests
   ```
7. Запустить `pytest --collect-only` и убедиться что fixtures видны

## Тесты (TDD)

- `tests/test_conftest.py`:
  - `test_redis_mock_rpush()` — вызывает `rpush` на моке, проверяет что вызван
  - `test_redis_mock_blpop_returns_none_timeout()` — проверяет поведение timeout
  - `test_temp_audio_wav_is_valid()` — проверяет что файл существует и имеет расширение .wav
  - `test_temp_dir_is_clean()` — проверяет что tmp_path пуст на входе
  - `test_matrix_client_mock_has_login()` — проверяет что mock имеет метод login
  - `test_real_audio_files_exist()` — проверяет что short.wav, medium.mp3, long.flac существуют
  - `test_real_audio_files_are_valid()` — проверяет что файлы валидны через `subprocess.run(['ffprobe', ...])`
  - `test_real_audio_files_have_correct_sample_rates()` — short.wav = 16kHz, medium.mp3 = 44.1kHz
