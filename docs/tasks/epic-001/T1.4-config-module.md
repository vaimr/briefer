# T1.4: Конфигурация на Pydantic Settings

## Описание
Создание типизированных конфигурационных классов `BotConfig` и `WorkerConfig` на базе `pydantic-settings`. Валидация обязательных полей, URL format, кастомные валидаторы.

**Эпик:** EPIC-001 (Foundation)  
**Зависимости:** T1.1 (Directory structure)  
**Оценка:** ~1.5 часа

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Переменные окружения (.env) | Pydantic BaseSettings с валидацией обязательных полей | `BotConfig` и `WorkerConfig` — типизированные, самодокументируемые конфиги |

---

## Критерии приёмки

- [ ] `bot/config.py` — класс `BotConfig(BaseSettings)` с полями:
  - `matrix_homeserver: str`
  - `matrix_user: str`
  - `matrix_password: str | None = None`
  - `matrix_access_token: str | None = None`
  - `redis_host: str = "redis"`
  - `redis_port: int = 6379`
- [ ] `worker/config.py` — класс `WorkerConfig(BaseSettings)` с полями:
  - `redis_host: str = "redis"`
  - `redis_port: int = 6379`
  - `llm_api_url: str`
  - `llm_model_name: str = "qwen3.6-a3b-mtp:35b"`
  - `whisper_model: str = "large-v3"`
  - `data_dir: str = "/data"`
  - `tz: str = "Europe/Moscow"`
  - `log_level: str = "INFO"`
  - `health_port: int = 8081`
- [ ] Обязательные поля (homeserver, user, redis_host, llm_api_url) — ValueError при отсутствии
- [ ] `matrix_password` и `matrix_access_token` — хотя бы один должен быть указан (кастомный валидатор)
- [ ] Типы: `redis_port: int = 6379`, `whisper_model: str = "large-v3"`, `data_dir: str = "/data"`
- [ ] `pydantic-settings>=2.0` добавлен в `bot/requirements.txt` и `worker/requirements.txt`

---

## Граничные случаи

- `matrix_password` и `matrix_access_token` — валидатор: если оба None → ValueError
- `matrix_homeserver` — валидация URL (должен начинаться с `http://` или `https://`)
- `llm_api_url` — валидация URL
- Значения по умолчанию для необязательных полей
- `.env` файл не существует → fallback на defaults (где возможно)

## Пошаговый план

1. Добавить `pydantic-settings>=2.0` в `bot/requirements.txt` и `worker/requirements.txt`

2. Создать `bot/config.py`:
   ```python
   from pydantic_settings import BaseSettings, SettingsConfigDict
   from pydantic import field_validator

   class BotConfig(BaseSettings):
       matrix_homeserver: str
       matrix_user: str
       matrix_password: str | None = None
       matrix_access_token: str | None = None
       redis_host: str = "redis"
       redis_port: int = 6379

       model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8")

       @field_validator("matrix_homeserver")
       @classmethod
       def validate_homeserver(cls, v: str) -> str:
           if not v.startswith(("http://", "https://")):
               raise ValueError("matrix_homeserver must be a valid URL starting with http:// or https://")
           return v

       @field_validator("matrix_password", "matrix_access_token")
       @classmethod
       def validate_at_least_one_auth(cls, v, info):
           # Проверяем что хотя бы один из password/token указан
           password = info.data.get("matrix_password")
           token = info.data.get("matrix_access_token")
           if password is None and token is None:
               raise ValueError("Either MATRIX_PASSWORD or MATRIX_ACCESS_TOKEN must be set")
           return v
   ```

3. Создать `worker/config.py` аналогично с полями worker-конфигурации

4. Написать тесты (см. ниже)
