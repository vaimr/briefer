# T1.1: Директорная структура и пакетный layout

## Описание
Создание базовой структуры проекта: директории, файлы-заглушки, `.gitkeep`, `.gitignore`.

**Эпик:** EPIC-001 (Foundation)  
**Зависимости:** нет (стартовая задача)  
**Оценка:** ~1 час

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Пустая директория проекта | Создание директорий и файлов-заглушек | Структура: `bot/`, `worker/`, `data/`, `tests/`, `tests/unit/`, `tests/integration/`, `tests/fixtures/` |

---

## Критерии приёмки

- [ ] Все директории созданы: `bot/`, `worker/`, `data/`, `tests/`, `tests/unit/`, `tests/integration/`, `tests/fixtures/`
- [ ] `tests/fixtures/.gitkeep` существует
- [ ] `data/.gitkeep` существует
- [ ] `.gitignore` содержит: `data/`, `__pycache__/`, `*.pyc`, `.env`, `*.pyo`, `node_modules/`
- [ ] `tests/conftest.py` существует (создаётся в T1.3, здесь — пустой placeholder)
- [ ] `bot/__init__.py` существует
- [ ] `worker/__init__.py` существует

---

## Граничные случаи

- Пустая директория `data/` не должна попадать в git → нужен `.gitkeep`
- Директория `tests/fixtures/` должна содержать `.gitkeep` для отслеживания в git
- `tests/unit/` и `tests/integration/` — пустые директории, тоже нужны `.gitkeep`

---

## Пошаговый план

1. Создать директории:
   ```bash
   mkdir -p bot worker data tests/unit tests/integration tests/fixtures
   ```
2. Создать `.gitkeep` файлы:
   ```bash
   touch data/.gitkeep tests/fixtures/.gitkeep tests/unit/.gitkeep tests/integration/.gitkeep
   ```
3. Создать `bot/__init__.py` и `worker/__init__.py` (пустые)
4. Создать `tests/conftest.py` (пустой placeholder — будет заполнен в T1.3)
5. Проверить `.gitignore` — убедиться что содержит:
   - `data/`
   - `__pycache__/`
   - `*.pyc`
   - `.env`
   - `*.pyo`
   - `node_modules/`
   - `.pytest_cache/`
   - `htmlcov/`
   - `*.egg-info/`
   - `.mypy_cache/`
6. Проверить через `git status` — никаких незакоммиченных данных

## Тесты (TDD)

Нет кода для тестирования — проверка через файловую систему:

- `tests/test_placeholder.py`:
  - `test_directories_exist()` — проверяет что `bot/`, `worker/`, `data/`, `tests/`, `tests/unit/`, `tests/integration/`, `tests/fixtures/` существуют
  - `test_gitkeep_files_exist()` — проверяет `.gitkeep` в `data/`, `tests/fixtures/`, `tests/unit/`, `tests/integration/`
  - `test_init_files_exist()` — проверяет `bot/__init__.py` и `worker/__init__.py`
  - `test_gitignore_contains_required()` — проверяет что `.gitignore` содержит ключевые паттерны
