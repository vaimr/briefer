# T1.5: CI-скелет и pre-commit

## Описание
Настройка CI/CD пайплайна: `.github/workflows/ci.yml`, `.pre-commit-config.yaml`, `Makefile` с целями test/lint/docker-build.

**Эпик:** EPIC-001 (Foundation)  
**Зависимости:** T1.3 (Test framework), T1.4 (Config)  
**Оценка:** ~1 час

---

## Spec

| Input | Обработка | Output |
|-------|-----------|--------|
| Python-проект | `.github/workflows/ci.yml` + pre-commit config | PR-пайплайн: lint → test → coverage threshold |

---

## Критерии приёмки

- [ ] `.github/workflows/ci.yml` — workflow на push/PR: устанавливает Python 3.11, pip install, pytest
- [ ] `.pre-commit-config.yaml` — black (88), isort, flake8 (или ruff)
- [ ] `Makefile` с целями: `make test`, `make lint`, `make docker-build`
- [ ] `make test` локально проходит
- [ ] `make lint` локально проходит
- [ ] Coverage threshold: минимум 60% для MVP

---

## Граничные случаи

- CI должен работать без доступа к Docker (тесты юнитов) и с Docker (интеграционные)
- Coverage threshold: минимум 60% для MVP
- Python 3.11 — точная версия в CI
- pre-commit hooks должны работать на Windows и Linux

## Пошаговый план

1. Создать `.pre-commit-config.yaml`:
   ```yaml
   repos:
     - repo: https://github.com/psf/black
       rev: 24.4.2
       hooks:
         - id: black
           args: ["--line-length", "88"]
     - repo: https://github.com/PyCQA/isort
       rev: 5.13.2
       hooks:
         - id: isort
     - repo: https://github.com/PyCQA/flake8
       rev: 7.1.0
       hooks:
         - id: flake8
   ```

2. Создать `.github/workflows/ci.yml`:
   ```yaml
   name: CI
   on: [push, pull_request]
   jobs:
     lint:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-python@v5
           with:
             python-version: "3.11"
         - run: pip install pre-commit
         - run: pre-commit run --all-files
     test:
       runs-on: ubuntu-latest
       needs: lint
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-python@v5
           with:
             python-version: "3.11"
         - run: pip install -r tests/requirements-dev.txt
         - run: pip install -r bot/requirements.txt
         - run: pip install -r worker/requirements.txt
         - run: pytest tests/ --cov --cov-fail-under=60
   ```

3. Создать `Makefile`:
   ```makefile
   .PHONY: test lint docker-build docker-up docker-down

   test:
       pip install -r tests/requirements-dev.txt
       pip install -r bot/requirements.txt
       pip install -r worker/requirements.txt
       pytest tests/ --cov --cov-fail-under=60

   lint:
       pre-commit run --all-files

   docker-build:
       docker compose build

   docker-up:
       docker compose up -d

   docker-down:
       docker compose down
   ```

4. Запустить `make test` локально и убедиться что проходит

## Тесты (TDD)

Нет кода для тестирования — проверка через запуск CI-локально:

- `tests/integration/test_ci.py`:

  - `test_makefile_lint_target_exists()` — проверяет что Makefile содержит target lint
  - `test_precommit_config_exists()` — проверяет что `.pre-commit-config.yaml` существует
  - `test_ci_workflow_exists()` — проверяет что `.github/workflows/ci.yml` существует
